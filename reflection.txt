Project Reflection — Vitrine (The Met Collection API)
=====================================================

How I approached the project
----------------------------
I started by choosing a public “Art Data” API for a visual website. The first
version used the Art Institute of Chicago API. Its JSON endpoints worked, but
their image host later began blocking many requests with Cloudflare (403), so
images failed while titles still loaded. I switched the live image source to the
Metropolitan Museum of Art Collection API, which is also free, needs no API key,
supports CORS, and serves images that load reliably in the browser.

The product flow stayed the same: land on one featured work, search the
collection, and open details. I used GET requests with fetch, read JSON, and
mapped fields like title, artist, and image URLs into the page.

What was hard
-------------
Learning that a public API can return good data while images still fail (because
the image CDN is separate and protected). Also, The Met’s search endpoint returns
object IDs only, so each result needs a second request to `/objects/{id}` — that
meant limiting how many detail requests run at once so the page stays fast.

What was easy
-------------
Building the layout and wiring buttons/search once sample JSON responses were
clear. Displaying titles and artists is straightforward after a successful fetch.

How I might improve for the next project
----------------------------------------
- Test both data and image URLs from a real browser early, not only the JSON.
- Plan loading and broken-image fallbacks before polishing the UI.
- Cache recent object responses and add pagination.

Biggest learning from today
---------------------------
REST APIs are more than one URL. Metadata and media can live on different hosts,
and both must work for the product to feel complete.

What I would do differently next time
-------------------------------------
I would verify hotlinked images on the deployed site (GitHub Pages) immediately,
and keep a backup public art API in mind if the first choice’s images are blocked.
